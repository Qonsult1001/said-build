# 300/300 = 1.0000 Perfect Recall on WikimQA

## Date: April 7, 2026

## Result
```
Baseline (SCA only):   286/300 = 0.9533
Combined (all layers): 300/300 = 1.0000
Fixed:                 14/14
Regressions:           0
Time:                  8.9s (300 queries)
```

## Pipeline
1. SCA 1-bit binary search (top-50 candidates) — 286/300
2. Grep re-rank (gw=1.0, entity extraction, per-phrase specific injection) — +14
3. Iterative multi-hop (gap < 1.5, bridge entities from top-3 docs) — catches last 1

## What this proves
- Cosine similarity is NOT required for perfect retrieval
- Vector databases are NOT required for perfect retrieval
- 8 bytes per document + grep + iterative = 100% recall
- No neural inference at search time
- No float vector storage
- No HNSW, no FAISS, no cosine, no dot product

## Config
- top_k: 50 (zero speed penalty vs top-10)
- grep_weight: 1.0
- iterative_gap_threshold: 1.5
- safe_injection: per-phrase specificity <= 5 docs
- injected_base_score: 0.8 * max_sca
