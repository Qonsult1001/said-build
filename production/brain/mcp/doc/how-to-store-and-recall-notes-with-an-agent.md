# How to store and recall notes through your AI agent

You've connected your brain to an agent (if not, do the
**[MCP tutorial](tutorial-connect-your-brain-to-an-agent.md)** first). This guide covers the everyday
pattern: getting the agent to save the right things and pull them back when you need them.

## Save a note

Just tell the agent, in plain language:

    Remember that our billing job runs at 02:00 every night.

The agent saves it and confirms. You can also be explicit about giving it a short name so you can find
it exactly later:

    Remember our office wifi is "sunflower-42" — call this note "wifi".

**The agent saves memories on its own, too.** It's set up to act as your note-taker — when you make a
decision, state a preference, or share a fact worth keeping, it will offer to remember it without you
asking. You can always say "don't save that" if you'd rather it didn't.

## Ask for it back

Ask in your own words — you don't need the exact wording you saved:

    When does our billing run?

The agent finds the note by **meaning** and answers, quoting what you stored. This works in any
conversation, including brand-new ones — the memory lives in the file, not the chat.

To check whether the brain has anything on a topic at all:

    Do I have anything saved about wifi?

If there's a match, the agent shows it. If not, it will tell you it found nothing rather than guessing.

## Read one note exactly

If you named a note (e.g. "wifi") and want its exact text, not a paraphrase, ask:

    Show me my saved wifi note word-for-word.

The agent reads it back verbatim.

## Fix or remove a note

**Changed your mind?** Just save the new version — tell the agent the updated fact and it stores it.
The brain keeps the older version in history (see
**[How to track versions of a memory](how-to-track-versions-with-an-agent.md)**).

**Want it gone?** Ask:

    Delete my wifi note.

The agent removes it. Deleted notes go to a recycle bin and can be recovered — see
**[How to recover a deleted memory](how-to-clean-up-your-brain-with-an-agent.md)**.

## If the agent can't find something

- **It says it has nothing on the topic** — the note may never have been saved, or was saved with very
  different wording. Ask it to save the fact now, then try again.
- **It answers from general knowledge instead of your brain** — remind it: "check my brain first." The
  agent is meant to treat your saved memories as the source of truth over its own training.
