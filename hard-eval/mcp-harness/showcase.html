100% carryover. Every one of 30 distinct fixes, learned interleaved across 2 projects, is recalled by loose paraphrase within the top-5 candidates. When a semantically-adjacent fix out-scores the exact one, the right fix is rank 2-3 — the agent picks it from the returned top-5 (the documented recall@5=100% contract). This suite found & fixed the bug that hid it: the MCP recall_fix tool returned only rank-1, so the agent couldn't page down — now it returns the top-K (see Findings #4).

Rust — cold✓Result<Self,String>, format! error

The finding: both arms compile — but the cold C# agent invented the wrong convention for this codebase; only the memory-primed agent matched house style (Guard.AgainstNullOrEmpty). Memory delivers convention-correctness, not just compile-correctness — the thing that matters in a real team codebase. Primed agents got the convention in ~200 recalled tokens instead of exploring for it.
