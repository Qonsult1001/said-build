100% carryover — even on hard paraphrases. A generalization battery of 15 varied paraphrase gaps — synonym swaps (floating point↔stored float, wraps around↔overflow), abbreviation, reordering, plain-english↔technical, and near-twins that must stay distinct — recalls the exact fix at rank 1, 15/15, with zero false positives on unrelated queries. Reaching this took finding the real bug: coding-fix recall was scored on the 1-bit fingerprint (which can't tell "float" from "floating point") and bypassed the documented float-cosine rerank that ask uses. Wiring that rerank into the fix path (re-encode query + each fix's task text, whitened cosine — the roadmap's recall@1 0.195→0.855 mechanism) closed it globally, not case-by-case (see Findings #5). Twin-precision + all recall tests stay green — it bridges synonyms without tying near-twins.

The finding: both arms compile — but the cold C# agent invented the wrong convention for this codebase; only the memory-primed agent matched house style (Guard.AgainstNullOrEmpty). Memory delivers convention-correctness, not just compile-correctness — the thing that matters in a real team codebase. Primed agents got the convention in ~200 recalled tokens instead of exploring for it.
