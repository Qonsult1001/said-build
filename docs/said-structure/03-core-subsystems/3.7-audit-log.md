# 3.7 — Audit log

Append-only BLAKE3-chained log of every mutating operation on a `.said` brain. Lives in [`crates/sca-core/src/audit.rs`](../../../crates/sca-core/src/audit.rs); persisted in the `AUDT` section.

## Motivation

Compliance + forensics. Every `remember`, `forget`, admin action needs a permanent trail. Without one:

- GDPR data-subject requests can't show who accessed or modified a given memory.
- SOX / HIPAA auditors can't verify retention sweeps honored legal holds.
- Debugging "why did this frame change" is a grep through CLI history.

With AUDT: one append-only section, BLAKE3-chained so tampering is detectable, queryable via CLI (`said admin audit`) or MCP (`admin action=audit`).

## Entry shape

```rust
pub struct AuditEntry {
    pub seq: u64,            // monotonic, first entry = 0
    pub timestamp: u64,      // unix epoch seconds
    pub actor: String,       // who: "owner" / user_id / app_id / "system"
    pub kind: String,        // what: remember / delete / forget / restore / legal_hold_add / ...
    pub target: String,      // which doc_id (or empty for global events)
    pub detail: String,      // freeform context ("frame #142 pillar=Semantic")
    pub hash: [u8; 32],      // BLAKE3(prev || seq || ts || actor || kind || target || detail)
}
```

## Chain verification

Each entry's hash depends on the previous entry's hash. Tampering with any past entry invalidates the chain from that point forward.

```rust
fn chain_hash(prev: &[u8; 32], seq: u64, ts: u64,
              actor: &str, kind: &str, target: &str, detail: &str) -> [u8; 32] {
    let mut hasher = blake3::Hasher::new();
    hasher.update(prev);
    hasher.update(&seq.to_le_bytes());
    hasher.update(&ts.to_le_bytes());
    hasher.update(actor.as_bytes());
    hasher.update(&[0u8]);
    hasher.update(kind.as_bytes());
    hasher.update(&[0u8]);
    hasher.update(target.as_bytes());
    hasher.update(&[0u8]);
    hasher.update(detail.as_bytes());
    *hasher.finalize().as_bytes()
}

pub fn verify(&self) -> Result<(), String> {
    let mut prev = [0u8; 32];
    for e in &self.entries {
        let expected = Self::chain_hash(&prev, e.seq, e.timestamp,
                                         &e.actor, &e.kind, &e.target, &e.detail);
        if expected != e.hash {
            return Err(format!("audit chain broken at seq={}", e.seq));
        }
        prev = e.hash;
    }
    Ok(())
}
```

Known kinds (so far):
- `remember` — frame written (from `remember_with_pillar` or explicit `remember_with_salience`)
- `delete` — `forget()` / `delete()` soft-delete
- `restore` — admin_restore on a tombstoned doc_id
- `legal_hold_add` — admin placed a legal hold
- `legal_hold_release` — admin lifted a hold
- `retention_sweep` — retention sweep marked a frame Deleted

## Auto-hooks (where entries are written)

Every mutating path in `SaidFile` has a `brain.audit.append(kind, target, detail)` call:

| Path | Kind | Target | Detail |
|---|---|---|---|
| `remember_with_pillar` | `remember` | doc_id | `"frame #{id} pillar={pillar:?}"` |
| `forget` | `delete` | doc_id | `"soft-delete via forget()"` |
| `admin_restore` | `restore` | doc_id | `"restored frame #{id} (displaced old head #{})"` |
| `admin_legal_hold_add` | `legal_hold_add` | doc_id | `"case={case} frames_tagged={n}"` |
| `admin_legal_hold_release` | `legal_hold_release` | doc_id | `"case={case} frames_released={n}"` |
| `mark_frame_deleted` | `retention_sweep` | (empty) | `"frame_id={id} marked deleted"` |

Only happens for callers that go through these methods. Direct `FrameStore::put_with` callers (e.g. `document_ingest.rs`) bypass the audit hook — see [Known limitations](../11-known-limitations.md) for the migration plan.

## Actor override

Callers can set the actor before a mutating call:

```rust
brain.audit_mut().set_actor("app:slack-pack");
brain.remember_with_pillar(...);
// audit entry has actor="app:slack-pack"
```

Portable brains default to `"owner"` (single-user). Enterprise brains should have the MCP server extract `app_id` from the request context and set it per-call.

**Known gap (2026-04-22).** MCP dispatch doesn't yet wire this up — actor defaults to `"owner"` for MCP-originated actions. [Limitation tracked here](../11-known-limitations.md#audit-log--actor-attribution-depends-on-caller-discipline-row-45).

## AppGrant — per-app capability restrictions

Parallel feature: `AppGrant` + `AppGrantRegistry` enforce which apps may invoke which action kinds. Enterprise-mode MCP dispatch should:

```rust
let registry = AppGrantRegistry::new();
registry.set_strict(true);  // Enterprise — reject unknown apps
registry.register(AppGrant::new("search-ui", vec!["remember".into(), "search".into()]));
registry.register(AppGrant::new("admin-tool", vec!["*".into()]));

// Before every mutating handler:
registry.check(app_id, action)?;
```

**Known gap (2026-04-22).** The registry exists + tests pass, but MCP dispatch doesn't construct one or call `.check()`. Enterprise deployments get the audit trail but not the enforcement until this gap closes. [Tracked here](../11-known-limitations.md#enterprise-mode--appgrant-registry-not-wired-into-mcp-dispatch-row-45).

## CLI surface

```
said admin audit                       # list entries
said admin audit --verify              # verify chain; prints "ok" or break point
said admin audit --actor alice         # filter by actor substring
said admin audit --kind delete         # filter by exact kind
```

JSON output (with `--json` at cli root) serializes each entry with hex-encoded hash for machine consumption.

## MCP surface

```json
{"name": "admin", "arguments": {"action": "audit"}}
```

Repurposes `doc_id` as the actor filter and `case` as the kind filter. Returns up to 200 entries + overflow count.

## On-disk — `AUDT` section

Layout:
```
[0..4]   b"AUDT"
[4..8]   u32 n_entries
per entry:
  [0..8]    u64 seq
  [8..16]   u64 timestamp
  [16..18]  u16 actor_len    + actor bytes
  [..+2]    u16 kind_len     + kind bytes
  [..+2]    u16 target_len   + target bytes
  [..+4]    u32 detail_len   + detail bytes
  [..+32]   [u8; 32] hash
```

**Magic-scanned** — not referenced in the header. Absent section = empty log (back-compat).

## Public API

```rust
pub struct AuditLog {
    // ...
}

impl AuditLog {
    pub fn new() -> Self;
    pub fn set_actor(&mut self, actor: impl Into<String>);
```

## Tests

4 unit tests in [`audit.rs`](../../../crates/sca-core/src/audit.rs):

1. `chain_is_consistent` — append 3 entries, verify passes
2. `chain_detects_tampering` — mutate an entry's `kind` after the fact, verify returns the break seq
3. `roundtrip_serialize` — serialize + deserialize preserves all entries; chain still verifies
4. `grant_check` — AppGrantRegistry strict mode refuses unknown apps; wildcard matches all

All green as of 2026-04-22.
