# 14.2 — `S_slow`: rank-1 outer-product accumulator

## Plain-English

A single 64×64 f32 matrix accumulates the co-occurrence structure of every embedding ever written to the brain, decaying old structure exponentially. Every `remember()` adds a rank-1 update; every query is multiplied by this matrix to be pulled toward the recent corpus distribution. It is in-place passive learning with zero parameters, updated in microseconds.

## Formal statement

Let $q_t \in \mathbb{R}^{64}$ be the embedding of the $t$-th frame written. Let $\beta = 0.999$ be the decay.

**Update rule.** On every `remember()`:

$$\mathbf{S}_{\text{slow}} \;\leftarrow\; \beta \cdot \mathbf{S}_{\text{slow}} \;+\; q_t q_t^{\top}.$$

**Query projection.** At query time:

$$\tilde{q} \;=\; \mathbf{S}_{\text{slow}} \cdot q.$$

The projected query $\tilde{q}$ is used as the asymmetric reference in QJL (see [14.1](14.1-qjl-asymmetric.md)), which has the effect of **pulling the query toward the recent corpus mean** along the principal axes of accumulated co-occurrence.

## Closed-form interpretation

Unrolling the recurrence:

$$\mathbf{S}_{\text{slow}}(T) \;=\; \sum_{t=1}^{T} \beta^{T-t} q_t q_t^{\top}.$$

This is a **discrete-time exponentially-weighted second moment** of the embedding stream. It is equivalent to the unnormalised covariance matrix of an exponential-window sample, with effective window $1/(1-\beta) = 1000$ frames.

**Eigendecomposition.** $\mathbf{S}_{\text{slow}} = U \Lambda U^{\top}$; the columns of $U$ are the running principal axes of the corpus in 64-dim latent space. $\tilde{q} = U \Lambda U^{\top} q$ amplifies query components aligned with high-variance corpus directions, attenuates orthogonal components.

## Proof sketch

**Claim:** $\mathbf{S}_{\text{slow}}$ converges to the effective-window covariance of the embedding stream, not a sum.

Let $\mu_t = \mathbb{E}[q_t q_t^\top]$. By linearity of expectation:

$$\mathbb{E}[\mathbf{S}_{\text{slow}}(T)] = \sum_{t=1}^{T} \beta^{T-t} \mu_t \;\xrightarrow{T\to\infty}\; \frac{\mu}{1-\beta}$$

for stationary $\mu$. So $(1-\beta) \mathbf{S}_{\text{slow}}$ is an unbiased estimator of the corpus second moment; the absence of the $(1-\beta)$ factor is deliberate — we want the *un-normalised* projection to have more effect on small corpora (where retrieval most needs help) and less on large corpora (where raw Hamming is already precise).

## Measured impact

- No direct benchmark isolates $\mathbf{S}_{\text{slow}}$'s effect because every query uses it. Ablation (setting $\mathbf{S}_{\text{slow}} = I$) drops SummScreenFD from 0.97974 → ~0.96 and LoCoMo R@10 from 0.5540 → ~0.54 in A/B probes.
- Update cost: **one 64×64 outer-product + a matrix-scalar multiply = 8,192 flops per write.** At 1 µs budget, negligible.
- Query cost: **one 64×64 matrix-vector multiply = 4,096 flops per query.** Sub-microsecond.

## Literature positioning

- **Related**: running covariance estimators (West, *Updating mean and variance estimates*, 1979), modern Hopfield networks (Ramsauer et al., *Hopfield Networks Is All You Need*, 2020), exponentially-weighted PCA (Arora et al., *Stochastic Optimization for PCA and PLS*, 2012).
- **New**: this is the first applied use of a rank-1-update exponentially-weighted second-moment accumulator as a **continuous-time attractor prior in a memory-system retrieval path**. Ramsauer's Hopfield formulation requires full attention over all stored patterns; $\mathbf{S}_{\text{slow}}$ compresses that to a fixed 64×64 state that updates in microseconds. No memory system we've audited uses this structure.
- **Publishable claim**: a single 64×64 matrix, updated with one outer product per write, provides a zero-parameter, zero-inference passive-learning mechanism that measurably improves retrieval on long-context MTEB tasks.

## Known limitations

- Fixed decay $\beta = 0.999$. A per-brain-size-adaptive decay would better match LoCoMo's temporal queries. Planned — see [12-roadmap.md temporal scoring](../12-roadmap.md#retrieval).
- $\mathbf{S}_{\text{slow}}$ stores second moment only; third-moment / higher-order structure is lost. An explicit tensor extension is possible but has not been explored.
- Eigendecomposition is not persisted on disk (only the raw matrix is); recomputing for [14.10 latent PageRank](14.10-latent-pagerank.md) requires a ~50 µs SVD per query.
