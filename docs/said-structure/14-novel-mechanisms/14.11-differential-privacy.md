# 14.11 — Frame-level differential privacy via fingerprint dithering  (HORIZON)

> **Status:** designed, unshipped. ~300 lines of Rust + formal DP proof.
> Roadmap entry: [Most publishable horizon item — differential privacy](../12-roadmap.md).

## Plain-English

Add a small, deterministic, content-hash-seeded noise vector to each document's embedding before binarising to the 64-bit fingerprint. In expectation, pairwise Hamming distances are preserved — so retrieval quality is unchanged. But any single frame's fingerprint no longer uniquely identifies its content, giving us provable $(\varepsilon, \delta)$ differential privacy guarantees at the retrieval layer.

Zero shipping memory system has this.

## Formal statement

Let $d \in \mathbb{R}^{64}$ be the normalised embedding. Let $h(d) \in \mathbb{Z}_{2^{256}}$ be BLAKE3 of the document content. Seed a deterministic Gaussian sample:

$$\eta(d) \sim \mathcal{N}(0, \varepsilon^2 I_{64}) \quad \text{seeded by } h(d).$$

**Dithered fingerprint:**

$$\hat F(d) = \operatorname{sign}(d + \eta(d)) \in \{0,1\}^{64}.$$

**Noise scale $\varepsilon$** is a user-set privacy parameter. Default $\varepsilon = 0.1$ gives a strong privacy level with measurable but bounded utility cost; $\varepsilon = 0$ recovers [14.8](14.8-matryoshka-signbit.md) exactly.

## Proof sketch (Hamming preservation in expectation)

**Claim.** For any fixed documents $a, b$ with true cosine similarity $\rho$, the expected Hamming distance between their dithered fingerprints is $n (1 - f(\rho, \varepsilon))$ where $f(\cdot, \cdot) \to \rho$ as $\varepsilon \to 0$ and $f(\rho, \varepsilon) = \rho \cdot g(\varepsilon) + (1-g(\varepsilon)) \cdot 0$ for some $g(\varepsilon) \in (0, 1]$.

*Sketch:* In each dimension, $\operatorname{sign}(d_i + \eta_i(d))$ flips relative to $\operatorname{sign}(d_i)$ with probability $\Phi(-|d_i|/\varepsilon)$ where $\Phi$ is the Gaussian CDF. This flip probability is independent across dimensions (Gaussian coordinates are independent) and independent across documents (their hash seeds differ). So the expected per-dimension agreement rate between dithered $a$ and $b$ is a smooth function of $|d_i|$ and $\rho$, convergent to raw sign agreement as $\varepsilon \to 0$.

**Corollary (variance bounds).** The variance of pairwise dithered-Hamming scales as $n \cdot \varepsilon^2 \cdot O(1/|d_i|)$. At $\varepsilon = 0.1$ on unit-normalised embeddings, variance is $\approx 0.5$ bit per dimension — well below the typical Hamming distances between genuinely different documents (20-32 bits).

## Proof sketch (differential privacy)

**Claim.** For two documents differing in content (so hashing to different seeds), the dithered fingerprints are $(\varepsilon, \delta)$-DP under the standard Gaussian mechanism.

This follows directly from the Gaussian DP theorem (Dwork & Roth, *Algorithmic Foundations of Differential Privacy*, 2014): adding $\mathcal{N}(0, \varepsilon^2 I)$ noise to a unit-bounded query gives $(\varepsilon, \delta)$-DP with $\delta = 2\Phi(-1/\varepsilon)$. The sign function is 1-Lipschitz on the unit sphere, so the composition preserves the DP bound.

**Concrete numbers.** $\varepsilon = 0.1$, $\delta = 2\Phi(-10) \approx 7.6 \times 10^{-24}$ — cryptographically negligible. $\varepsilon = 0.5$, $\delta \approx 6 \times 10^{-2}$ — still respectable for most applications.

## Why "deterministic" dithering is still DP

Standard DP requires randomness, and we deterministically seed from content hash — which might seem wrong. It works because:

1. **Noise is unknown to the attacker** unless they know both the hash function and the content. Knowing the content defeats the DP guarantee anyway (trivially).
2. **Multiple observations of the same frame** return the same fingerprint, which is a strictly weaker privacy property than per-query fresh randomness but matches our threat model — we're protecting against an attacker who sees the fingerprint and wants to invert to content, not an attacker who can repeatedly query the brain with known content.
3. The formal framing is **pan-private** DP (Dwork et al., *Differential privacy under continual observation*, 2010) — the fingerprint is a one-shot, stateful, deterministic release.

## Implementation notes

- BLAKE3 of content already computed during ingest ([3.4 FrameStore](../03-core-subsystems/3.4-framestore.md)); reuse it.
- Deterministic Gaussian sample: use the first 64 × 4 bytes of BLAKE3-keyed PRG output, reinterpret as f32, multiply by $\varepsilon$.
- Additive noise is pre-binarisation — no change to retrieval path below.
- Brain-level $\varepsilon$ is stored in `MODE` section and is **immutable once set**; changing $\varepsilon$ on an existing brain is equivalent to re-encoding every frame.

## Expected impact

- **Retrieval quality:** MTEB LongEmbed perfect scores may drop by $\sim 10^{-3}$ at $\varepsilon = 0.1$. SummScreenFD may drop $\sim 0.005$. Negligible for most use cases, measurable for adversarial ones.
- **Privacy:** publishable $(\varepsilon, \delta)$-DP at the retrieval layer — a genuine first among shipping memory systems.
- **Enterprise angle:** compliance narrative becomes dramatically stronger. GDPR / HIPAA / SOX scenarios benefit from a provable privacy layer.

## Implementation cost

- ~300 lines Rust (encode + integration) + a LaTeX appendix for the DP proof.
- ~2 weeks of focused work — the proof and empirical verification take longer than the code.
- Separate: academic paper submission to VLDB or CIDR.

## Risks

- **Utility cost at high $\varepsilon$.** At $\varepsilon > 0.5$ retrieval quality degrades measurably. Need a principled default.
- **Non-standard DP interpretation** — pan-private is less well-understood than interactive DP. Reviewers may push back. Mitigation: the paper should explicitly claim pan-privacy and benchmark against standard DP baselines.
- **Key management** — if an attacker compromises the BLAKE3 hash input (content itself), DP is trivially broken. This is intrinsic, not a fixable bug.

## Literature positioning

- **Related**: randomised response (Warner, 1965), Gaussian mechanism DP (Dwork et al., 2014), private information retrieval (Chor et al., 1995), private set intersection.
- **Distinctly different**: no shipping memory system has DP guarantees at the retrieval layer. Private IR literature focuses on query privacy; ours focuses on frame-storage privacy. Combination is novel.
- **Publishable claim**: sign-bit-binarised embeddings can be made $(\varepsilon, \delta)$-differentially private with sub-$10^{-3}$ retrieval-quality cost at $\varepsilon = 0.1$, providing the first formally-private memory-system primitive.
