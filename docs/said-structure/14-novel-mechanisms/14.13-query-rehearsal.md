# 14.13 — Query-side continuous rehearsal  (HORIZON)

> **Status:** designed, unshipped. Zero-gradient "learning" at retrieval time.
> Roadmap entry: [Wait-and-see horizon item — query rehearsal](../12-roadmap.md).

## Plain-English

Track the last $K$ queries as a 64 × $K$ matrix. When a new query arrives, blend it with its projection onto the column space of recent queries. Recently-rehearsed topics retrieve more sharply; one-off queries are unaffected. No gradients, no training data, just linear algebra. Effectively a rolling cache of "user intent" that sharpens retrieval without becoming a retrieval cache.

## Formal statement

Let $Q_t = [q_{t-K+1}, q_{t-K+2}, \dots, q_t] \in \mathbb{R}^{64 \times K}$ be the matrix of the last $K$ query embeddings (default $K = 32$).

**Rehearsal blend.** For a new query $q$:

$$\operatorname{proj}_{Q_t}(q) = Q_t (Q_t^\top Q_t)^+ Q_t^\top q$$

where $(\cdot)^+$ is the Moore–Penrose pseudo-inverse (numerically stable via SVD of $Q_t$). Then:

$$q_{\text{rehearsed}} = (1 - \lambda) \cdot q + \lambda \cdot \operatorname{proj}_{Q_t}(q)$$

with $\lambda \in [0, 1]$ tunable (default $\lambda = 0.2$).

**Update.** After retrieval, push $q$ into $Q_t$, evict the oldest column.

## Proof sketch

**Claim (idempotent when $q$ is in-distribution).** If $q$ is nearly in the span of recent queries, $\operatorname{proj}_{Q_t}(q) \approx q$, so $q_{\text{rehearsed}} \approx q$ — no change. The blend only has an effect when $q$ is *partially* in-distribution, which is the interesting case.

**Claim (zero effect on one-off queries).** If $q$ is orthogonal to the column space of $Q_t$, $\operatorname{proj}_{Q_t}(q) \approx 0$, so $q_{\text{rehearsed}} = (1-\lambda) q$. Scaled-down, not changed in direction. QJL similarity is invariant to query scaling. So: no effect.

**Claim (sharpening for recently-rehearsed topics).** If $q$ is close to a recent query, the projection aligns the two, averaging out noise. Repeated queries in a session converge to a denoised mean — the "getting warmer" behaviour during a long session.

## Implementation notes

- State size: $64 \times 32 \times 4 = 8192$ bytes. Trivial.
- $Q_t^\top Q_t$ is a $K \times K$ Gram matrix, $K=32$: 4096 f32s. Pseudo-inverse via SVD: ~$K^3 = 32{,}768$ flops per query. Sub-microsecond.
- Can cache the SVD and update incrementally as queries come in (down-dating one column, up-dating another). Not strictly necessary.
- Lives in the brain's transient state (not persisted on save); session-scoped.

## Expected impact

- **Sessions with topic coherence** (repeated questions about the same domain) should see measurable retrieval-precision improvement within the session.
- **LoCoMo temporal Cat 3** might benefit indirectly: if a user asks "what did Alice say last Thursday", then "about what topic", both queries share Episodic context; the second sharpens via projection onto the first.
- **Hard to predict without benchmarking.** Session-based benchmarks aren't in our standard suite — we'd need to build one.

## Implementation cost

- ~150 lines Rust (ring buffer + small SVD + blend).
- ~3-5 days of dev + benchmark design.
- Risk: the benchmark doesn't exist yet, so the feature is unlaunchable until a session-harness is built.

## Risks

- **Topic drift within a session.** If the user switches context (from coding to meeting-recall mid-session), rehearsal might drag the new query toward old topics. Mitigation: auto-reset $Q_t$ on a gap > 5 minutes, or on explicit "new topic" signal.
- **Over-smoothing.** $\lambda$ too high and every query collapses toward the session mean — same result for different questions. Tuning needed.
- **No persistent benefit** — rehearsal state is session-local. For cross-session benefit, would need a per-user state file, which complicates the single-file portability story.

## Literature positioning

- **Related**: subspace tracking (Yang, *Projection approximation subspace tracking*, 1995), streaming PCA, in-context learning in LLMs (Brown et al., 2020) — conceptual cousin but implemented in latent embedding space with no neural network.
- **Distinctly different**: in-context learning relies on a transformer's attention to capture intent from prior turns. Ours is a pure linear-algebra projection operating on query embeddings — no inference, no parameters.
- **Publishable claim**: session-scoped subspace-projection rehearsal provides a gradient-free, inference-free mechanism for in-session retrieval sharpening, with measurable impact on coherent-topic sessions.

## Known reasons for the "wait-and-see" priority

Of the five horizon items, this is ranked last because:

1. **Benchmark is unclear.** LoCoMo, MTEB, SummScreenFD are single-query benchmarks — they don't show rehearsal gains.
2. **Effect is session-scoped.** Harder to demonstrate than a one-shot improvement.
3. **Compositional risk with [14.10 latent PageRank](14.10-latent-pagerank.md).** Both modify the query embedding; interaction must be carefully measured.
