getting them back out by asking questions.

## Start here

- **[Tutorial: Your first portable brain](tutorial-your-first-brain.md)** — zero to first success.
  Create a brain, store notes, ask it a question. Start here if you've never used `said`.

## How-to guides (one task each)

- **[Store and recall personal notes](how-to-store-and-recall-notes.md)** — add notes over time, fetch
  them back, delete what you don't need.
- **[Set a default brain file](how-to-set-a-default-brain.md)** — stop typing `--path` on every command.
- **[Find a memory](how-to-find-a-specific-memory.md)** — `ask` (find by meaning) and `get`
