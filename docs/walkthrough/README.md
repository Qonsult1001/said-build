# `said` walkthroughs — brain (memory) basics

Hand-held, step-by-step docs for using `said` as a portable personal memory — storing notes and
getting them back out by asking questions.

## Start here

- **[Tutorial: Your first portable brain](tutorial-your-first-brain.md)** — zero to first success.
  Create a brain, store notes, ask it a question. Start here if you've never used `said`.

## How-to guides (one task each)

Everyday:

- **[Store and recall personal notes](how-to-store-and-recall-notes.md)** — add notes over time, fetch
  them back, delete what you don't need.
- **[Find a memory](how-to-find-a-specific-memory.md)** — `ask` (find by meaning) and `get`
  (fetch by id). The two commands you actually need.
- **[Set a default brain file](how-to-set-a-default-brain.md)** — stop typing `--path` on every command.

Going further:

- **[Track versions of a memory and undo a change](how-to-track-versions-of-a-memory.md)** — see a
  memory's history and roll it back.
- **[Recover a deleted memory](how-to-recover-a-deleted-memory.md)** — restore from the recycle bin
  (and how to permanently clear it).
- **[Import memories from another tool](how-to-import-memories-from-another-tool.md)** — bring in
  memories from mem0 / memvid.
