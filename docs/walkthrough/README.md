# `said` walkthroughs — brain (memory) basics

Hand-held, step-by-step docs for using `said` as a portable personal memory — storing notes and
getting them back out by asking questions.

There are **two ways to use your brain**, and a walkthrough for each:

- **From the terminal (CLI)** — you type `said` commands yourself. Start with the tutorial below.
- **Through an AI agent (MCP)** — your agent (Claude, Cursor, …) reads and writes the brain for you,
  and remembers things automatically. See **[the MCP path](#use-it-through-an-ai-agent-mcp)**.

Same brain file, either way — pick whichever fits how you work.

## Start here (terminal / CLI)

- **[Install `said`](how-to-install-said.md)** — download and set it up on Windows, macOS, or Linux.
  Do this first.
- **[Tutorial: Your first portable brain](cli/tutorial-your-first-brain.md)** — zero to first success.
  Create a brain, store notes, ask it a question. Start here once `said` is installed.

## Use it through an AI agent (MCP)

- **[Tutorial: Connect your brain to an agent](mcp/tutorial-connect-your-brain-to-an-agent.md)** — zero to
  first success over MCP. Connect the brain to Claude/Cursor, have it remember a fact, then recall it
  in a fresh chat.
- **[Store and recall notes through your agent](mcp/how-to-store-and-recall-notes-with-an-agent.md)** — the
  everyday save-and-ask pattern (the agent saves things for you automatically).
- **[Move your brain to another agent or machine](mcp/how-to-move-your-brain-to-another-agent.md)** — one
  file, any MCP agent.

## How-to guides — terminal / CLI (one task each)

Everyday:

- **[Store and recall personal notes](cli/how-to-store-and-recall-notes.md)** — add notes over time, fetch
  them back, delete what you don't need.
- **[Find a memory](cli/how-to-find-a-specific-memory.md)** — `ask` (find by meaning) and `get`
  (fetch by id). The two commands you actually need.
- **[Set a default brain file](cli/how-to-set-a-default-brain.md)** — stop typing `--path` on every command.

Going further:

- **[Track versions of a memory and undo a change](cli/how-to-track-versions-of-a-memory.md)** — see a
  memory's history and roll it back.
- **[Recover a deleted memory](cli/how-to-recover-a-deleted-memory.md)** — restore from the recycle bin
  (and how to permanently clear it).
- **[Import memories from another tool](cli/how-to-import-memories-from-another-tool.md)** — bring in
  memories from mem0 / memvid.
